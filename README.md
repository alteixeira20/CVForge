# CVForge

**Local-first CV builder and ATS parser workbench.**

CVForge is a privacy-first tool for creating compact, organized, and ATS-friendly CVs. All processing happens locally in your browser — no account, no sign-up, and no data leaves your machine.

## Key Features
- **Builder Workbench**: Real-time CV editing with live PDF preview.
- **Parser Workbench**: Deep diagnostics and ATS scoring for any resume PDF.
- **Import Hub**: Seamlessly restore sessions or import data from existing PDFs/JSON.
- **A4 & Letter Support**: Native support for EU (A4) and US (Letter) formats.
- **Privacy-First**: Zero server-side processing of your personal data.

## Getting Started
```bash
pnpm install
pnpm dev
```

## Architecture
This project follows a clean-room rebuild strategy, using a Next.js 15 + React 19 foundation adapted from the Forge-family visual style.
